Memory Optimization

Пропозиції щодо оптимізації використання пам'яті:

1. Не завантажувати весь файл у пам'ять одним String, а читати файл пострічково.

2. Не створювати масив String[] words для всього тексту, оскільки він може займати значний обсяг пам'яті.

3. Обробляти слова окремого рядка та одразу додавати їх частоти до Map.

4. Не зберігати одночасно весь текст, масив усіх слів та Map з частотами.

5. Не створювати окрему колекцію для унікальних слів, оскільки Map уже зберігає унікальні слова та їх частоти.

6. Не створювати окремий масив для збереження частот слів.

7. Не створювати окремий масив для збереження результатів перед їх виведенням.

8. Не створювати окрему колекцію для результатів сортування, а використовувати Stream API для сортування та безпосереднього виведення результатів.

9. Використовувати try-with-resources для автоматичного закриття потоку читання файлу.

10. Винести значення кількості результатів у константу TOP_WORDS замість використання магічного числа 30.

11. Вимірювати використання пам'яті до та після виконання основної операції.

12. Вимірювати час виконання за допомогою System.nanoTime().

13. Виводити час виконання та використану пам'ять для подальшого порівняння з попередньою версією програми.
